# Fraction Equivalence Tutor

An iPad app that teaches 9-year-olds fraction equivalence through interactive fraction bars and a scripted conversational tutor.

Students explore fractions by splitting, shading, and comparing rectangular bars. When two bars are lined up and the shaded regions match, the equivalence is visible — no memorization required. A scripted tutor guides the student through the lesson with a warm, encouraging voice. A lightweight LLM (Claude Haiku) acts as a safety net for edge cases the script can't anticipate — unexpected student actions, misconception classification, and dynamic hints when the student is stuck beyond what the script covers.

## How it works

The app presents two stacked fraction bars of equal width. The student taps segments to shade them, splits pieces into smaller parts, and combines adjacent pieces. The scripted tutor watches the student's actions and responds at key moments:

- When the student creates a fraction, the tutor names it ("You just made two-fourths!")
- When two bars show equivalent fractions, the tutor draws attention to the alignment
- When the student makes a common error, the tutor redirects without giving the answer away
- When the student is stuck, the tutor offers a hint after a short wait

All of these responses are pre-written in the lesson script. The lesson follows a fixed progression — free exploration, guided discovery, then assessment — and every planned path has authored dialogue.

When the student does something the script doesn't have a branch for (an unusual fraction, an unexpected sequence of actions), the LLM generates a short, contextual redirect. This happens maybe 10% of the time. The other 90% is pure script — instant, predictable, tested.

## Running locally

### Prerequisites

- Node.js 20+
- npm 10+
- Xcode 15+ (for iPad deployment)
- An Anthropic API key (optional — enables the LLM safety net for edge cases; the app is fully functional without it using scripted dialogue only)

### Install and start

```bash
git clone <repo-url>
cd fraction-tutor

npm install

# Start the dev server (browser)
npm run dev
```

The app opens at `http://localhost:5173`. Use Chrome DevTools device emulation set to iPad landscape (1194 x 834) for the intended layout.

### Environment variables

Create a `.env` file in the project root:

```
VITE_TUTOR_API_URL=http://localhost:8787
```

This points to the API proxy that holds your Anthropic key. See the proxy section below.

### Running the API proxy locally

```bash
cd proxy

# Install wrangler (Cloudflare Workers CLI)
npm install

# Set your API key
echo "ANTHROPIC_API_KEY=sk-ant-..." > .dev.vars

# Start the local proxy
npx wrangler dev
```

The proxy runs at `http://localhost:8787` and forwards requests to the Anthropic API with your key attached.

### Building for iPad

```bash
# Build the web app
npm run build

# Sync with Capacitor
npx cap sync ios

# Open in Xcode
npx cap open ios
```

In Xcode, select your iPad (or simulator), then Build and Run. The app locks to landscape orientation automatically.

## Lesson design

The lesson script (`src/tutor/lessons/equivalence.json`) defines a sequence of nodes. Each node has a type:

- **message** — Tutor speaks a pre-written line and auto-advances. No LLM involved.
- **prompt** — Tutor speaks and presents tappable response buttons. The student's choice determines the next node. All paths are scripted.
- **wait_for_action** — Tutor watches the fraction bars. When the student's manipulative state matches a target condition (e.g., bar 2 shows 2/4 shaded), the lesson advances with scripted dialogue. A scripted hint appears after 15 seconds of no progress.
- **check** — Assessment node. Correct and known-incorrect answers follow scripted branches. If the student's action doesn't match any known branch, the LLM safety net generates a contextual redirect.

The lesson progression for fraction equivalence:

1. Introduction — tutor explains the fraction bar, student explores freely
2. Build 1/2 — student shades half of a bar (guided)
3. Split and compare — student splits the second bar into 4 parts, shades 2, sees alignment with 1/2
4. Generalize — repeat with 2/3 = 4/6
5. Non-example — student checks whether 1/2 = 1/3 (it doesn't line up)
6. Assessment — 3 equivalence problems with increasing difficulty

## Offline support

The entire lesson — all dialogue, hints, feedback, and assessment — is scripted and bundled in the app. The app is fully functional offline. The only difference without network connectivity is that the LLM safety net is unavailable, so unrecognized student actions fall through to a generic scripted redirect ("Try looking at the bars again. Do the colored parts line up?") instead of a contextual LLM-generated response. Lesson progress persists locally via Capacitor Preferences.
